UMC Desk 테스트 앱 설치 안내

macOS 26 이상이 필요합니다. Apple Silicon·Intel Mac에서 사용할 수 있습니다.
터미널이나 개발 도구는 필요하지 않습니다.

1. GitHub Pre-release에서 UMC-Desk-0.0.1-build번호.dmg 파일을 다운로드합니다.
2. DMG 파일을 더블클릭합니다.
3. UMC Desk 앱을 오른쪽 Applications 폴더로 드래그합니다.
   이전 테스트 앱이 실행 중이면 먼저 종료하고, 교체 안내가 나오면 대치를 선택합니다.
4. 응용 프로그램 폴더에서 UMC Desk를 더블클릭합니다.
   인터넷에서 받은 앱을 열겠냐는 macOS 확인 창이 나오면 '열기'를 선택합니다.
5. 설치가 끝나면 Finder에서 UMC Desk 디스크를 추출합니다.

이 배포본은 Developer ID 서명과 Apple 공증을 완료했습니다.
앱 버전은 0.0.1이며 배포할 때마다 빌드 번호가 올라갑니다.
업데이트도 새 DMG를 받아 같은 순서로 앱을 교체하면 됩니다.

문제가 있으면 DMG 파일 이름(버전·빌드 번호), 스크린샷,
문제가 발생한 동작을 개발자에게 알려주세요.
보안 경고가 나오면 경고 화면을 개발자에게 전달해주세요.
