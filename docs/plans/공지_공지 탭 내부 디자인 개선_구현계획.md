680/960pt와 분할 폭은 승인 설계의 화면 치수이며 Figma 확정값이나 신규 전역 토큰이 아니다.

## 비GUI 검증

- `make build CODE_SIGNING_ALLOWED=NO`
- `make test SCHEME=NoticePresentation CODE_SIGNING_ALLOWED=NO`
- `make test SCHEME=NoticeDomain CODE_SIGNING_ALLOWED=NO`
- `make build CONFIGURATION=Release CODE_SIGNING_ALLOWED=NO`
- 프로젝트 스크립트 테스트와 PR의 Xcode 27.2 CI

회귀 테스트는 선택 상태의 낭독, 미확인 읽음 상태를 추정하지 않는 표현, 상호 배타적인 빈 상태,
동일 필터 실패 보존·재시도 페이지, 필터 변경 및 전체/개별 권한 회수 범위를 다룬다.
간격 숫자 복제 테스트나 production 테스트 훅은 추가하지 않는다.

## 실제 창 검수 인계

항목44 창 조율 대기 중이므로 앱 실행·기존 앱 종료·전역 입력·XCUITest를 실행하지 않는다.
창 검수·키보드·IME·VoiceOver·접근성 설정은 아직 통과로 판정하지 않는다.
독립 코드 리뷰는 쿠리만쥬, 설계 일치/시각 검수는 히치와레가 같은 후보 SHA에서 수행한다.

격리 빌드 앱: `UMCDesk/Build/Products/Debug/UMC Desk.app`.
허용된 창 인계 후 **보기 → 데이터 미리보기 → 공지**를 사용한다.
미리보기는 세션 전용 저장소와 fixture를 사용한다. 실제 계정·Keychain·실서버를 사용하지 않는다.

| 로컬 시나리오 | 기존 fixture/재현 경로 | 한계 |
| --- | --- | --- |
| 고정·투표·링크 | 챌린저 공지 ID 21, 데모데이 안내 | 기존 2개 투표 선택지·정상 마감 |

| 긴 제목·작성자·URL/사진/복구 상태 | 검수자가 사용하는 기존 로컬 fixture 조율 필요 | 앱 공통 fixture·다른 작업자의 fixture는 수정하지 않음 |

캡처는 `/tmp`에만 저장한다. 같은 SHA의 캡처가 확보되기 전 PR은 Draft로 유지하며,
검수 누락과 외부 조율 조건을 PR에 명시한다. 병합·자동병합·배포는 수행하지 않는다.
