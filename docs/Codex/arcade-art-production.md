## 1. 부두에서 먼저 보여야 할 것 정하기

**입력**은 설계의 남쪽 접수대 시야, 서문 세로줄과 동문 톱니, 안전 통로, 인장이 차지할 전경이다. `game-art`로 먼저 명도표를 만든 뒤 같은 표를 `imagegen`의 배경 프롬프트에 붙인다.

> 접수대 눈높이에서 중앙 광장 너머의 둥근 소인기를 본다. 원경 건물은 옅은 회색 덩어리와 가는 선으로 묶는다. 바닥은 밝은 미색 종이로 넓게 비우고 서문 세로줄과 동문 톱니가 보이게 한다. 광장의 손짓과 위험 띠가 들어갈 자리를 비워 둔다. 문자, 캐릭터, HUD는 그리지 않는다.

**예상 산출물**은 원경 레이어, 바닥·문 표지 레이어, 전경까지 얹은 회색조 축소 시안이다. 명도 스케일을 검정 0~흰색 100으로 놓으면 원경은 70~85 사이의 좁은 범위, 바닥 바탕은 90 전후, 캐릭터 외곽과 인장 접촉면은 15 전후에서 시작해 볼 수 있다. 수치는 시안용이다. 경고 주황은 곧 발동할 위험에만 쓰고 사선 밀도와 실선 테두리로 발동 전후를 구별한다. 실제 창에서 먼저 눈에 드는 것이 종루의 창살이라면 그 선의 대비부터 낮춘다.

## 2. 투명 기준 컷에서 키포즈 뽑기

먼저 `sprite-animation`으로 그림 장수와 표시 시간을 정한다. 아래는 60 Hz 화면에서 한 표시 간격을 약 16.7 ms로 잡은 **포즈 노출 예시**다. 사람의 회피 가능 시간은 이동 거리와 속도까지 넣어 정하며, 원화 장수가 위험 판정 시각을 결정하지 않는다.

| 입력과 역할 | 내장 imagegen에 줄 프롬프트 예시 | 예상 산출물과 화면에서 읽을 사건 |
| --- | --- | --- |
| 미키 기준 컷, 서문 위치. 손짓은 방향 안내 | “기준 컷의 얼굴·귀·장갑 비율과 먹선을 유지한다. 접수대에서 서문 쪽 팔꿈치를 몸통 밖으로 빼고 손끝을 세로줄 문으로 뻗는다. 발 위치와 시점은 고정한다. 전신 한 자세, 투명 배경.” | 준비 100 ms → 가리키기 300 ms → 팔 내림 150 ms의 세 컷. 손끝과 몸통 사이 빈 공간으로 방향이 보인다. |
| 서문 문턱과 접지콩의 착지 칸. 위험 예고는 회피 판단 | “문턱의 깃발이 펴지는 자세를 그린다. 별도 바닥 그림에는 착지할 한 칸만 사선과 삼각 표식으로 채운다. 옆 통로는 비운다. 배경 투명.” 각 그림은 한 번씩 요청한다. | 깃발 → 점선·사선 예고 → 발동 실선. 예시로 예고 그림을 600 ms 유지하고 발동 그림을 100 ms 보인다. 손짓을 놓쳐도 위험 칸과 빈 길을 구분해야 한다. |
| 꾹이의 인장 기준 컷, 손잡이와 조준점 위치. 날인은 입력 피드백 | “같은 손잡이 비율과 먹색 인면을 유지한다. 손목을 접어 인면이 조준점 아래로 내려와 종이에 닿는 순간을 한 자세로 그린다. 손목 기준점과 시점 고정, 배경 투명, 잉크 자국은 별도.” | 입력에 바로 반응하는 들기 50 ms → 압착 50 ms → 회수 100 ms. 적중은 닫힌 원과 펴진 표적, 빗나감은 작은 점. 접촉 자세를 기다리느라 입력 처리가 늦어지지 않아야 한다. |

기준 컷이 없으면 먼저 중립 자세 하나를 생성해 작업자가 고른다. 로컬 기준 컷은 열어서 확인한 다음 편집 대상으로 지정한다. 매번 선택한 같은 원본에 “가리키는 팔만 변경”처럼 한 가지 변경을 요청한다. 장갑 크기·종이 접힘·광원·선 굵기·카메라 각도는 고정한다. 각 인물과 효과를 따로 생성하며 투명 요청에는 `transparent_background=true`를 사용한다. 결과를 흰색과 먹색 바탕에 번갈아 올려 체크무늬가 그려진 배경, 흰 테두리, 잘린 손끝을 찾아낸다.

## 3. 셀을 맞추고 실제 게임 프레임에 올리기

**입력**은 선택한 기준 컷과 키포즈, 목표 창의 pt·배율·렌더 픽셀, 원거리에서 가장 작게 보이는 캐릭터 높이다. 예를 들어 “미키의 팔을 끝까지 편 자세가 들어가는 공통 128×128 px 셀, 좌상단 원점에서 양발 사이 (64, 118)”을 정렬 지시로 쓴다. 팔을 더 뻗어 셀이 좁아지면 모든 컷의 셀과 피벗을 함께 조정한다.

- 미키는 발 중앙, 꾹이의 전경 인장은 손목, 찍힌 효과는 인면 접점을 고정 피벗으로 삼는다. 접촉점이 움직이는 컷은 셀 안의 해당 좌표를 별도 앵커로 기록한다. 포즈마다 외곽에 맞춰 잘라 가운데 정렬하면 발이나 손잡이가 튄다.
- **인계 예시**는 투명 원화, 같은 크기의 셀을 동작별 한 줄로 모은 시트, 각 셀의 이름·피벗·앵커·표시 시간(ms)·반복 여부를 적은 표다. 셀 가장자리에 1~2 px 여백을 두고 확대·축소할 때 이웃 셀의 잉크가 묻어나는지 본다. 날인과 예고에는 끝 포즈를 둔다.
- **표시 판정**은 게임 카메라, 바닥, HUD를 함께 본다. 예를 들어 960×540 pt 창, 2배율, 1920×1080 px 렌더 표면에서 미키가 세로 48 pt면 실제로는 96 px다. 가장 먼 문 앞과 가장 가까운 문 앞에서 각각 장갑 방향을 알아보는지, 인장이 내려와도 위험 칸과 조준점이 보이는지 확인한다. 같은 위치에서 정지 자세를 번갈아 표시해 발이 미끄러지거나 손목이 튀면 피벗부터 고친다.

## 4. 첫 10초 판독과 별도 Release 실측

첫 부두에서 **손짓이 시작되는 순간부터 10초간** 같은 경로와 입력으로 검수한다. 처음 보는 사람에게 조작만 알려 주고, 실제 크기·정상 속도에서 한 번 본 뒤 답과 시각을 적는다. 아래 구간은 검수 장면의 예시이며 플레이어 입력에 따라 사건 시각이 달라진다.

| 관찰 구간 예시 | 판정자가 볼 것 | 통과 기준 |
| --- | --- | --- |
| 0~3초 · 미키의 손짓 | “어느 문을 봤나요?” | 방향 안내 문구를 읽어 주기 전에 서문을 가리킨다. 손이나 문이 HUD 뒤에 숨지 않는다. |
| 3~6초 · 위험 예고 | “어느 칸으로 피했나요?” | 발동 전에 사선 칸을 벗어나 빈 통로로 이동한다. 회색조·무음에서도 표식으로 같은 선택을 한다. |
| 6~10초 · 꾹이의 날인 | “소인이 맞았나요? 무엇을 보고 알았나요?” | 손 입력 직후 첫 화면 변화와 표적 반응을 구별한다. 같은 장면의 빗나감 재시도에서는 작은 점으로 차이를 설명한다. |

동작 줄이기에서는 정지 손짓과 고정 위험 무늬로 같은 질문을 확인한다. 예고 시간은 유지한다. 기록에는 SHA, 창 pt·배율·렌더 px, 설정, 최초 오독 시각과 그때 가려진 윤곽을 적는다. 한 번에 한 가지(예: 원경의 창살 명도)만 고친 뒤 같은 조건에서 다시 본다.

**성능은 같은 SHA의 Release 구성에서 녹화를 끄고 따로 측정한다.** 설계의 제안 환경은 M1·8 GB·60 Hz, 실제 렌더 표면 1920×1080 px다. 예열 한 판 뒤 같은 경로로 세 판을 측정한다. 각 판의 첫 파동·두 번째 파동 최대 밀집·보스 마지막 두 띠에서 실제 표시 간격 p95 ≤ 17 ms, p99 ≤ 33.4 ms, 50 ms 초과 0건인지 본다. 원본 타임라인과 환경·구간별 집계는 [부두 실측 기록표](dock-action-game.md#실행-증빙과-프레임타임-기록표)에 남긴다. 10초 장면의 판독 결과와 Release 수치는 각각 독립해서 기록한다.

| 후보와 입력 자료 | 프롬프트 예시와 예상 산출물 | 실제 크기에서 볼 첫 10초 |
| --- | --- | --- |
| 바람 접기 · 종이 한 장의 기준 컷, 접는 선과 바람 방향 | “종이의 고정 모서리를 축으로 끝만 들어 올린다. 바람길은 성긴 선, 접힌 면은 넓은 회색 면으로 분리한다.” 펼침·들림·접힘 세 컷과 모서리 피벗 표 | 손을 떼기 전 바람 방향을 짚고, 접은 뒤 모서리가 어느 쪽을 향하는지 말한다. 가장 작은 종이에서도 세 컷의 고정점이 흔들리지 않아야 한다. |
| 너울 한 술 · 수면선, 숟가락 기준 컷, 접촉 높이 | “수면의 봉우리 한 곳을 남기고 잔물결 대비를 낮춘다. 손잡이를 고정해 숟가락이 닿는 컷과 떠 올린 컷을 분리한다.” 수면 레이어, 진입·접촉·회수 컷, 접점 표 | 봉우리가 닿을 위치를 먼저 짚고, 뜬 직후 숟가락 안쪽 실루엣으로 성공과 빈 숟가락을 구별한다. 무음에서도 결과가 읽혀야 한다. |
