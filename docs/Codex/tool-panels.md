# macOS 도구 패널

작성자: 제옹(euijjang97) · 기준일: 2026-11-28

탭의 도구는 창 오른쪽 위 슬라이더 버튼으로 연다. 공지에서 제목·본문을 검색하거나 스레드에서 새 대화를 만들 때처럼, 패널을 열어도 사용자가 보던 목록과 선택은 유지한다. 닫힌 버튼·열린 패널의 크기, 색, 위치는 [디자인 시스템의 확정 사양](design-system.md#우측-상단-도구-버튼과-패널)을 따른다. 사용자가 직접 변경을 지시한 범위만 앱·Figma·문서에 함께 반영한다.

## 패널 안에 둘 동작

| 화면 | 사용할 수 있는 도구 | 상태에 따른 차이 |
| --- | --- | --- |
| 홈 | 일정·공지·프로젝트 이동, 새로고침 | 해당 데이터가 있을 때 바로가기가 생긴다. |
| 공지 | 제목·본문 검색, 빠른 보기, 게시 기간·대상 필터, 작성 | 결과가 비어도 조건을 바꿀 수 있다. 작성 권한을 확인한다. |
| 활동 | 출석, 스터디 그룹, 구성원 찾기, 운영 | 선택한 하위 탭과 그룹의 권한에 따라 바뀐다. |
| 스레드 | 제목·소개 검색, 만들기, 분류·참여 필터 | 첫 스레드를 만들 수 있고 전체 보기로 필터를 되돌릴 수 있다. |
| 커뮤니티 | 게시글 검색, 새 글, 범위·카테고리 | 범위에 적용되는 카테고리를 제공한다. |
| 프로젝트 | 프로젝트 찾기·이어가기, 할 일, 연결 관리 | 목록과 상세가 서로 다른 도구를 제공한다. |
| 프로젝트 매칭 | 탐색·일정·내 지원·운영 | 선택한 차수·프로젝트와 권한에 맞춰 운영 화면에 진입한다. |
| 매칭 진행 결과 | 내 지원, 매칭으로 이동, 갱신 | 작은 별도 창에서도 버튼과 끝 행에 접근할 수 있어야 한다. |
| 마이페이지 | 활동 코드, 프로필 링크, 새로고침, 설정 | 프로필 로드 및 계정 작업 상태를 따른다. |
| 설정 | 설정 검색, 검색어 지우기, 항목 이동 | 사용자 지정 색상과 기존 검색 추천을 유지한다. |
| 고객센터 | 도움말·FAQ, 내 문의, 문의 관리 | 사용자·운영 권한, 문의 선택과 작성 중 이탈 확인을 따른다. |

탭별 세부 명령과 데이터·권한의 근거는 [도구 패널 설계](<../specs/도구패널_탭별 기능과 우측 상단 배치_설계.md>)에 있다.

## 구현과 검수

창 작업면에 `umcTabToolsHost()`를 두고 활성 화면에서 `umcTabTools`로 명령을 제공한다. 긴 필터는 넓은 패널을 사용한다. 패널 검색과 본문 검색은 해당 화면의 상태와 제출 경로를 공유한다. 권한을 확인하는 화면으로 들어가는 명령은 기존 확인·취소 경로를 거친다. [공통 구현](../../UMCDesk/Core/UIComponents/Sources/UMCTabTools.swift) · [텍스트 필드 가이드](text-fields.md)

보기 메뉴의 **전체 데이터 있음**과 **전체 빈 화면**에서 탭을 바꾸며 확인한다. 실제 첫 빈 상태와 필터로 생긴 빈 결과를 각각 열어, 전자에서 가능한 첫 행동과 후자에서 조건을 지우는 행동을 실행한다. 입력 중에는 포커스 테두리가 하나인지, Esc로 닫은 뒤 같은 창의 도구 버튼에 포커스가 돌아오는지, 첫 바깥 클릭이 뒤쪽 명령을 실행하는지 확인한다. 바깥 클릭은 패널만 닫아야 한다.
