# 나만의 공간 — 홈과 세 가지 미니게임

작성자: 제옹(euijjang97)

## 1. 목적과 범위

앱을 열면 필요한 소식을 간단히 확인하고 할 일이 없을 때 짧게 게임을 즐길 수 있습니다.
나만의 공간은 관리 지표를 빽빽하게 나열하는 화면 대신 오늘 일정·공지·최근 작업만 보여 줍니다.
게임은 블록 점프·벽돌 깨기·타이밍 탑 쌓기 세 가지입니다. 각 게임의 기록을 따로 쌓습니다.

이번 범위는 홈, 첫 사용, 게임 선택, 플레이, 결과, 재시작과 로컬 기록입니다.
전국 순위·친구 경쟁·보상 상점·일일 접속 의무·계정 간 점수 공유는 추가하지 않습니다.

## 2. 공통 대시보드

메인 창은 1440×960, 창 안쪽 여백은 12입니다. 검은색 탐색 레일은 56px,
콘텐츠 패널은 x=80부터 시작하며 폭 1348px, 높이 936px입니다.
콘텐츠는 Light와 Dark를 제공하고 두 모드의 탐색 레일은 같은 검은색을 유지합니다.

| 요소 | 기준 |
|---|---|
| 창 외곽·레일 바탕 | `macOS/Shell/background` · 두 모드 모두 `#0F1010` |
| 레일 아이콘 | `semantic/Text/default`의 Dark 값 `#F7F8F8` · 레일에 Dark 모드 고정 |
| 현재 메뉴 | `semantic/Fill/primary/medium`의 Dark 값 `#013733` · 아이콘은 흰색 유지 |
| 메뉴 순서 | 나만의 공간 → 공지 → 활동 → 스레드 → 프로젝트 → 매칭 → 문의 |
| 보조 메뉴 | 구분선 → 탐색 펼치기 / 하단 내 계정 · 클릭하면 프로필 메뉴에서 설정 진입 |
| 클릭 영역 | 메뉴마다 44×44 · hover와 키보드 포커스에 메뉴명 표시 |
| 상단 탐색 | 높이 56 · 왼쪽 이전·앞으로 각 44×44 · 간격 12 · 제목·경로·사이드바 토글 제거 |
| 상단 기능 | 오른쪽 기존 탭 도구 모음·새로고침·검색·작성 등 기능 버튼 유지 |

공지·활동·스레드·프로젝트·매칭·문의·계정과 검토·보관 화면에도 같은 탐색 메뉴를 적용합니다.
각 화면의 현재 메뉴 강조와 본문 내용은 유지합니다. 로그인·점검 화면과 독립 시트에는 탐색 레일을 넣지 않습니다.

## 3. 홈 정보와 게임 선택

로그인과 시작 검증을 마치면 H1을 기본 홈으로 엽니다. 마지막 상세 화면은 해당 메뉴로 돌아갔을 때 복원합니다.
홈 조회만으로 공지를 읽음 처리하거나 출석을 요청하지 않습니다.

| 영역 | 표시 정보와 행동 |
|---|---|
| 인사 | 이름·현재 날짜 · 작은 보조 문구 |
| 오늘 일정 | 가장 가까운 일정 한 건 · 일정 상세로 이동 · 출석 가능 여부는 기존 판정 사용 |
| 공지 | 읽지 않은 공지 수·대표 제목 · 공지 목록으로 이동 |
| 이어서 작업 | 마지막 개인 프로젝트 기능·작업 시각 · 저장한 작업으로 이동 |
| 게임 선택 | 같은 크기의 카드 3개 · 이름·규칙 한 줄·플레이 장면·조작법·최고 기록·한 판 하기 |
| 나의 기록 | 게임별 누적 점수·클리어한 기록 단계·다음 목표 |
| 최근 플레이 | 최근 종료한 3판의 게임명·점수·날짜 |

게임 카드를 누르면 해당 게임의 새 판을 시작합니다. 플레이 화면에도 세 게임 전환과 게임 선택으로 돌아가는 버튼을 둡니다.
진행 중 게임을 바꾸거나 Esc를 누르면 현재 판을 종료하고 얻은 점수를 한 번만 기록합니다.
앱이 비활성화되거나 창이 최소화되면 게임과 타이머를 일시정지합니다.

첫 사용 화면에도 세 게임을 모두 제공합니다. 일정·공지·최근 작업이 없으면 각 영역의 빈 상태를 표시합니다.
게임 기록은 최고 0점·누적 0점·0/3 단계로 시작하며 실제 플레이 없이 샘플 기록을 저장하지 않습니다.

## 4. 세 가지 게임

아래 규칙과 점수는 이번 기획에서 정한 초안입니다. 구현 후 플레이 테스트로 난이도와 속도를 조정합니다.

| 게임 | 조작 | 재미를 만드는 규칙 | 판 종료·클리어 | 점수 |
|---|---|---|---|---|
| 블록 점프 | Space 또는 클릭 | 장애물을 넘으며 점차 빨라짐 · 점프 타이밍으로 최고 기록 갱신 | 충돌하면 종료 | 넘은 장애물마다 10점 |
| 벽돌 깨기 | 마우스 또는 ← →로 패들 이동 · Space로 공 발사 | 패들로 공을 튕겨 10개 벽돌을 제거 · 패들에 맞은 위치에 따라 반사 방향 변화 | 공을 놓치면 종료 · 벽돌 10개 제거 시 클리어 | 벽돌당 50점 · 클리어 시 `max(0, 500 - 10 × floor(플레이 초))` 보너스 |
| 타이밍 탑 쌓기 | Space 또는 클릭으로 블록 놓기 | 좌우로 움직이는 블록을 아래 블록에 맞춤 · 벗어난 부분은 잘려 다음 블록이 좁아짐 · 중앙 오차 3px 이내면 PERFECT | 겹침이 없으면 종료 · 20층이면 클리어 | 층당 10점 · PERFECT마다 추가 20점 |

벽돌 깨기는 공 한 개와 패들 한 개로 시작합니다. 멀티볼·아이템·다중 스테이지는 이번 범위에 없습니다.
타이밍 탑 쌓기는 첫 바닥 블록을 층수에 포함하지 않습니다. PERFECT면 폭을 유지하고
그 외에는 겹친 폭만 다음 층에 남깁니다. 한 판의 20층 목표와 누적 점수의 기록 단계를 구분합니다.

성공 피드백은 벽돌 소멸·짧은 PERFECT 표시·새 최고 기록 안내로 전달합니다.
게임 선택과 재시작은 즉시 반응합니다. 화면 전체를 흔드는 효과나 홈의 반복 애니메이션은 사용하지 않습니다.
소리는 기본 꺼짐이며 동작 줄이기 설정에서 장식 효과를 줄여도 조작과 판정은 같습니다.

## 5. 기록과 단계

최고 기록과 누적 점수는 게임별로 계산합니다. 서로 다른 게임의 점수를 하나의 공용 점수로 합치지 않습니다.
누적 점수는 정상 종료·사용자 종료·클리어 시 확정한 각 판의 점수를 더합니다.
같은 판의 결과 화면을 다시 열거나 재시작해도 중복으로 더하지 않습니다.

| 기록 단계 | 조건 | 표시 |
|---|---|---|
| 1단계 | 해당 게임 누적 500점 이상 | 1/3 단계 |
| 2단계 | 해당 게임 누적 1,500점 이상 | 2/3 단계 |
| 3단계 | 해당 게임 누적 3,000점 이상 | 3/3 단계 · 모든 기록 단계 완료 |

한 판으로 여러 기준을 넘으면 넘은 단계를 모두 반영합니다. 3단계를 마친 뒤에도 최고 기록과 누적 점수는 계속 쌓습니다.
결과 화면은 이번 판 점수·게임별 최고·누적 점수·단계를 보여 주고 한 판 더와 게임 선택을 제공합니다.
블록 점프의 2단계 클리어는 누적 기록 단계 도달을 뜻하며 벽돌 10개·탑 20층의 판 클리어와 구분합니다.

## 6. 로컬 저장과 네트워크

게임 실행과 점수 계산은 네트워크 요청 없이 처리합니다. 시작 검증을 마친 앱에서 연결이 끊겨도
게임은 계속할 수 있습니다. 서버 정보 영역은 조회 실패·재시도를 표시하고 새 일정이나 공지가 없다고 단정하지 않습니다.
앱 최초 로그인·세션 만료·앱 실행 시 시작 검증은 기존 정책을 따릅니다. 비로그인 오프라인 시작 경로는 이번 범위에 없습니다.

기록은 같은 Mac의 로그인 계정별 로컬 저장소에 둡니다. 로그아웃 시 저장소를 잠그고 같은 계정의 재로그인 후 복원합니다.
다른 Mac과 동기화하거나 UMC 역할·출석·활동 평가에 점수를 반영하지 않습니다.
점수 저장에 실패하면 결과에 저장 실패를 표시하고 재시도할 수 있게 합니다. 확정하지 못한 점수는 누적에 더하지 않습니다.
앱이 강제 종료되면 마지막으로 확정한 기록을 유지하며 진행 중 판은 복구하지 않습니다.

| 저장 항목 | 목적 |
|---|---|
| 계정 로컬 키·게임 종류·기록 버전 | 계정과 게임별 분리 |
| 판 식별자·종료 시각·이번 판 점수·종료 사유 | 최근 플레이와 중복 기록 방지 |
| 최고 기록·누적 점수·달성 단계 | 홈과 결과 표시 |

2026-09-30 서버 main 파일 트리 조회에서는 게임·점수 도메인 경로를 확인하지 못했습니다.
게임을 위해 새 API가 이미 있다고 가정하지 않습니다. 일정·공지 데이터는 기존 기능 계약을 그대로 사용합니다.

## 7. 화면과 프로토타입

| ID | 화면 | 확인할 흐름 |
|---|---|---|
| H1 | 나만의 공간 · 기본 / 첫 사용 | 세 게임 선택 · 기존 정보 상세 이동 |
| H2 | 블록 점프 · 플레이 | 플레이 예시 → 누적 2단계 결과 / 종료 |
| H3 | 블록 점프 · 2단계 클리어 | 한 판 더 / 게임 선택 |
| H4 | 블록 점프 · 한 판 종료 | 점수 반영 예시 / 다시 시작 |
| H5 | 벽돌 깨기 · 플레이 | 패들·공·남은 벽돌 → 클리어 예시 |
| H6 | 벽돌 깨기 · 클리어 | 이번 판·최고·누적 / 다시 시작 |

실시간 물리·랜덤 장애물·충돌 판정·기록 저장은 앱 구현에서 검증합니다. Figma 프레임 전환을 실제 플레이로 설명하지 않습니다.

## 8. 수용 기준

- 모든 메인 대시보드에 검은색 레일과 첫 항목 나만의 공간이 표시됩니다. 현재 메뉴 강조를 유지합니다.
- 홈에서 세 게임의 규칙과 조작법을 읽고 한 번의 선택으로 시작할 수 있습니다.
- 세 게임을 각각 종료·클리어·재시작하고 게임 선택으로 돌아갈 수 있습니다.
- 같은 판은 한 번만 기록됩니다. 재시작은 새 판 식별자를 사용합니다.
- 게임별 최고·누적·500/1,500/3,000점 단계가 서로 섞이지 않습니다.
- 첫 사용, 정보 조회 실패, 기록 저장 실패를 실제 데이터가 없는 상태와 구분합니다.
- 연결이 끊겨도 이미 열린 게임이 작동합니다. 홈의 서버 영역은 실패 상태를 정확히 표시합니다.
- 키보드 포커스가 게임 영역에 있을 때만 게임 키를 처리합니다. 메뉴 탐색 단축키를 빼앗지 않습니다.
- 클릭 영역 44px 이상과 게임 이름·버튼의 접근성 이름을 제공합니다. 키보드로 시작·조작·종료할 수 있습니다.
- 동작 줄이기와 소리 꺼짐에서도 점수·판 종료·클리어를 시각적으로 확인할 수 있습니다.
