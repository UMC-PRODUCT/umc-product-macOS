# 검색과 폼 입력 공통 적용

작성자: 제옹(euijjang97)
작성일: 2026-11-28

## 사용자 흐름과 범위

공지 도구의 두꺼운 시스템 포커스 링을 해소한다. 설정 검색의 여백·아이콘·지우기 동작과 사용자가 첨부한 채팅 검색 및 이름 변경 화면을 기준으로 검색은 캡슐, 일반 한 줄 입력은 둥근 사각형으로 구분한다. Light·Dark 토큰과 대비, 최소 36pt 높이, 조절되는 글자 크기, 한 겹의 식별 가능한 포커스 테두리를 사용한다. 앱의 단일행 TextField·SecureField 및 AppKit 검색을 조사하고 동일 패턴을 적용한다. OTP 칸, 인라인 편집, 여러 줄 편집기처럼 목적·레이아웃이나 검증 계약이 다른 입력은 원래 동작을 보존하고 적용 경계를 기록한다. 공유 버튼·패널 자체의 확정 외형과 명령은 유지한다.

## 계약 및 검증

호출부가 검색어·초안·선택 및 포커스 소유권을 유지한다. 검색 시점(실시간/Return), IME 조합과 Return·Esc·방향키·⌘F, 비밀번호 가림, validation·disabled, VoiceOver 레이블, 버튼 중복 제출 방지와 통화/숫자 포맷을 검증한다. 지우기는 필드 내용만 비우고 포커스를 유지한다. 설정의 사용자 테마 색과 추천 표시를 보존한다. 오류는 색 이외에도 기존 메시지로 식별한다. 두 사진의 폼·검색 형태를 실제 앱 캡처로 대조한다.

## 담당별 구현 지시

1. 공통 컴포넌트·설정·인증 담당은 CoreUIComponents에 기존 TextField에 적용하는 공개 .umcInputField() 와 검색 전용 컨테이너 UMCSearchField를 제공한다. AppKit 기반 IME/검색은 원래 컨트롤과 delegate를 감쌀 수 있게 한다. 실제 SwiftUI 포커스 바인딩을 이중 지정하지 않도록 호출부를 점검한다. Settings와 Auth의 모든 입력을 조사하고 테마·SecureField·validation·특수 OTP 등 기존 계약을 보존한다. API를 즉시 팀에 공유한다.
2. 검색·콘텐츠 담당은 Notice, Activity, Community, ProjectWorkspace의 모든 입력을 검색하고 패널/본문 검색에는 공통 검색 UI, 폼에는 공통 입력을 적용한다. ThreadSearchField 네이티브 편집기의 한글 조합 처리 및 focusRequest를 유지한다. 필드 클리핑·내부 여백 중첩, 입력한 검색어 지우기·재입력·폼 에러를 검증한다.
3. 매칭·고객센터 담당은 Matching 및 UMCDesk 앱 모듈의 단일행 입력 전체를 담당한다. 검색·폼을 구분하며 폼 에디터와 문의 native 입력의 식별자·Return·Esc·취소 보호·검색 리셋과 포커스 이동을 보존한다. 기능별 스타일 중복을 제거한다. 소유한 테스트와 빌드를 점검한다.
4. 독립 리뷰는 변경 후 모든 필드 호출부와 포커스, 조합 문자열, 접근성, 정보 유출/비밀번호, 작은 창·스크롤, 중복 여백을 확인한다. 신규 문서에서 현재 소스에 없는 기능을 설명하지 않는지 대조하고, 재현 가능한 문제는 담당자에게 전달한다.
5. 문서 담당은 docs/Codex에 패널 및 텍스트 필드 레퍼런스를 각각 작성하고 AGENTS.md, 디자인 시스템 가이드, 기존 탭별 설계와 상호 연결한다. 실제 적용 대상과 예외를 명시하고 사용자가 직접 변경 지시하는 규칙을 보존한다.

각 담당자는 기존 작업 트리와 타인의 변경을 보존하고 소유한 파일 안에서만 구현한다. 결과는 변경 지점, 테스트, 미확인 항목을 구분해 보고한다.

6. Figma 담당은 공통 입력 구현에서 확정된 토큰·치수와 아래 가이드를 기준으로 기존 Mid-Fi/Hi-Fi에서 패널 안 실제 검색 입력과 재사용되는 검색/폼 원본을 확인한다. 검색으로 이동하는 버튼은 입력 필드와 구분한다. 공지 제목·본문 및 스레드 제목·소개 패널의 입력을 우선 적용하고 공통 원본에서 전파되는 곳과 독립 프레임을 구분한다. 기존 프로토타입 링크·창 모드·문자열을 보존하며 확정된 열기 버튼·패널 외곽을 변경하지 않는다. 필요한 상태(기본/내용 있음/포커스)를 참조할 수 있도록 하고 수정·검증한 노드 링크를 문서 작성자에게 보고한다.
