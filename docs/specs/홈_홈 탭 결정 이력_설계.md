## 홈에서 오늘의 업무 확인하기

로그인한 회원이 홈을 열면 닉네임으로 인사한다. 프로필을 처음 받기 전이나 조회에 실패한 경우 기본 제목은 ‘나만의 공간’이며, 이미 받은 프로필이 있으면 유지한다. 앱이 현재 계정의 네트워크 클라이언트와 회원 ID를 홈에 전달한다. 홈 카드는 정보를 조회하고, 버튼은 해당 업무의 탭을 연다. [계정 연결](../../UMCDesk/UMCDesk/Sources/Composition/FeatureAccount.swift) · [앱의 탭 이동](../../UMCDesk/UMCDesk/Sources/App/UMCDeskApp.swift)

| 카드 | 어떤 항목을 보여 주나 | 누르면 |
| --- | --- | --- |
| 일정 | 현재 시각부터 로컬 달력 기준 오늘 끝까지 내 일정을 출석 필요·불필요로 나누어 요청한다. 두 응답을 합쳐 시작 시각이 가장 이른 항목의 날짜·이름·시각을 표시한다. | 활동 탭 |
| 공지 | 활성 기수의 챌린저 공지 목록에서 첫 제목을 표시한다. | 공지 탭 |
| 프로젝트 | 활성 기수에서 내가 관리하는 프로젝트 목록의 첫 이름을 표시한다. | 프로젝트 탭 |

프로필·일정·공지·프로젝트는 각각 도착하는 대로 표시한다. 새로고침을 눌러도 직전에 읽은 항목은 응답이 올 때까지 남는다. 카드 조회가 실패하면 해당 영역에 실패 문구가 나오며 상단 ‘새로고침’으로 다시 조회한다. [조회 범위](../../UMCDesk/Features/Home/Data/Sources/HomeData.swift) · [조회 계약 테스트](../../UMCDesk/Features/Home/Data/Tests/HomeContractTests.swift)

대표 카드는 일정이다. 일정이 비었다는 응답을 받아야 프로젝트를 올리고, 프로젝트까지 비었다는 응답을 받아야 공지를 올린다. 승격된 항목은 보조 카드에서 빠진다. 일정 조회 중에는 대체 표시를, 실패하면 일정 오류를 보여 준다. 다음 후보의 결과가 대기 중이거나 실패했을 때도 일정 자리를 유지한다. 세 조회가 모두 빈 결과를 반환하면 ‘표시할 일정, 프로젝트, 공지가 없어요’ 한 장만 남고 업무 이동 버튼이 사라진다. [홈 화면과 상태 선택](../../UMCDesk/Features/Home/Presentation/Sources/HomePresentation.swift) · [부분 응답·승격 테스트](../../UMCDesk/Features/Home/Presentation/Tests/DeskSummaryTests.swift)


## 종이 달력과 창 너비

업무 카드에 배정된 폭이 960pt 이상이면 대표 카드와 보조 열을 2:1로 놓는다. 620pt 이상 960pt 미만에서는 대표 카드 아래에 보조 카드를 나란히 놓고, 620pt 미만에서는 세로로 쌓는다. 대표 카드만 남으면 전체 폭을 쓴다. 달력 삽화는 대표 카드 폭이 536pt 이상이고 제목이 80자 이하일 때 보인다. 긴 제목은 줄을 바꾸고 시작 시각과 버튼은 아래에 둔다. [카드 배치](../../UMCDesk/Features/Home/Presentation/Sources/DeskCardLayout.swift) · [제목과 삽화 표시](../../UMCDesk/Features/Home/Presentation/Sources/HomePresentation.swift)

라이트와 다크에 맞춰 종이·잉크·버튼 색을 바꾸고, 대비 증가 설정에서는 테두리를 진하게 그린다. 종이결과 삽화는 접근성 트리에서 숨긴다. 날짜·제목·시각은 묶어 읽으며, 보조 카드에는 제목·내용과 이동할 탭을 안내한다. [종이 표면](../../UMCDesk/Features/Home/Presentation/Sources/DeskPaper.swift) · [화면 접근성](../../UMCDesk/Features/Home/Presentation/Sources/HomePresentation.swift)

## 첫 부두와 내 기록

〈소인이 찍겠습니다!〉 카드의 ‘한 판 하기’에서 첫 부두에 입장한다. 접수대에서 첫 소인을 찍고 두 차례의 파동과 보스를 거쳐 결과에서 재도전하거나 홈으로 돌아온다. 카드에는 부두의 최고점·누적 점수와 최근 세 판의 점수가 표시된다. 진행 중 홈으로 돌아오면 그 판의 점수는 저장하지 않는다. [홈 화면](../../UMCDesk/Features/Home/Presentation/Sources/HomePresentation.swift) · [부두 세션](../../UMCDesk/Features/Home/Presentation/Sources/DockSession.swift)

부두 점수는 회원별 `home.postmarkDock.records.<회원 ID>`에 저장한다. 이전 공용 게임 저장소에만 부두 기록이 있으면 거기서 부두 점수만 읽고 원래 데이터는 보존한다. 회원 ID가 비어 있으면 저장하지 않는다. [부두 기록 저장소](../../UMCDesk/Features/Home/Presentation/Sources/DockRecordStore.swift)

**보기 → 데이터 미리보기**에서는 ‘전체 데이터 있음’과 ‘전체 빈 화면’ 모두 예시 세션 안에서 부두를 실행할 수 있다. 이전 게임의 예시 점수는 채우지 않는다. [미리보기 창](../../UMCDesk/UMCDesk/Sources/App/DataPreviewWindow.swift) · [미리보기 계정](../../UMCDesk/UMCDesk/Sources/Composition/DataPreviewAccount.swift)

## 변경 전 기록 · 기존 게임 세 종

홈 정리 전에는 ‘게임 선택’을 펼치면 세 게임의 설명·조작·최고점과 ‘한 판 하기’가 나타났다. 아래 표는 당시 규칙이다. [이전 홈 화면](https://github.com/UMC-PRODUCT/umc-product-macOS/blob/ebcbdc4/UMCDesk/Features/Home/Presentation/Sources/HomePresentation.swift)

| 게임 | 조작과 득점 | 종료 |
| --- | --- | --- |
| 블록 점프 | 바닥에 있을 때 Space 또는 클릭으로 점프한다. 장애물을 통과할 때마다 50점. | 장애물에 부딪히면 종료. 1,500점에서 클리어. |
| 벽돌 깨기 | 마우스를 움직이거나 ←·→ 키로 패들을 옮긴다. 벽돌 하나당 50점. | 공을 놓치면 종료. 벽돌 24개를 모두 깨면 클리어. |
| 타이밍 탑 쌓기 | Space 또는 클릭으로 움직이는 블록을 놓는다. 아래 블록과 겹친 폭만 다음 층에 남고 한 층마다 50점. | 겹치는 부분이 없으면 종료. 받침 위로 20층을 쌓으면 클리어. |

당시 게임은 창이 비활성화되면 멈췄고, 진행 중 Esc는 현재 점수로 판을 끝냈다. ‘홈으로’를 누르면 저장 없이 돌아갔다. [이전 보드](https://github.com/UMC-PRODUCT/umc-product-macOS/blob/ebcbdc4/UMCDesk/Features/Home/Presentation/Sources/GameBoard.swift) · [이전 판정](https://github.com/UMC-PRODUCT/umc-product-macOS/blob/ebcbdc4/UMCDesk/Features/Home/Domain/Sources/MiniGame.swift)

당시에는 게임별 최고점·누적 점수와 전체 최근 세 판을 보관했고 누적 500·1,500·3,000점에서 단계가 올랐다. 현재 홈에서 이 세 게임의 실행 경로·점수 표시를 제거했으며, 회원이 이미 저장한 기록은 남겨 둔다. [이전 기록 저장소](https://github.com/UMC-PRODUCT/umc-product-macOS/blob/ebcbdc4/UMCDesk/Features/Home/Presentation/Sources/HomeGameRecordStore.swift)

## 다음 변경을 기록하는 방법

홈의 동작·시안·탐색·기록 정책이 바뀌면 같은 PR에서 해당 단락을 고친다. 위 이력에 시점, 달라진 사용자 행동, 변경 이유와 근거를 추가하고 기준 커밋을 갱신한다. 개발 중인 게임은 병합된 뒤 실제 진입점과 기록 키를 확인해 현행 목록에 반영한다.

검수할 때는 바꾼 흐름을 데이터 있음·빈 화면에서 따라간다. 요약 변경은 조회 지연·실패와 재시도, 승격, 실제 이동할 탭을 확인한다. 배치 변경은 620·960pt 경계, 긴 제목, 라이트·다크와 대비 증가, 키보드 포커스와 VoiceOver 발화를 확인한다. 게임 변경은 종료와 중도 복귀의 기록 차이, 회원·미리보기 전환 시 점수 분리를 확인한다. 해당 PR에 검증 결과와 직접 확인한 범위를 남긴다.
